# cedar-act-sub-LAB

Tester-tier standalone: "Does Privilege's Cedar match the agent's act.sub claim? A measured run, simulated here." Structure forked from pf-privilege-obo-LAB.

- Run: `npm ci && npm start` (port 7819, the next free port in the shelf registry; catalog id D134 is provisional) or `docker compose up --build -d`
- Test: `npm test` (node --test + vitest + repo checks), `npm run doctor`. Owner-only real probe: `npm run real` (needs a local `.env`, see `.env.example`).
- Rules that bite: mock by default; the Real toggle is DISABLED with a reason and `POST /api/mode {"source":"real"}` answers 409 (the server never calls out; netguard + self-test stay on). Real is only `scripts/real-probe.mjs`, run by the owner in a terminal; it never creates or deletes tenant policies and prints the access token it was issued on purpose (a learning lab), never the client secret or the Basic value. Loopback-only publish, example ids only (`agent-client-example`, `agent-b-example`, `door-example`, `.example` hosts), the mock token of a run is shown whole and labelled mock-issued (rule 4); the server never shows or logs a real token or client secret.
- The mock door (`server/src/cedar.js`) evaluates ONE rule shape (the act.sub template). It is not a Cedar engine; say so wherever it is described. Scenario data and the static measured evidence (labelled 2026-11-16, kept apart from mock runs) live in `server/src/scenarios.js`.
- What the mock door did (Rule 25; the panel is titled "What the mock door did (simulated)" through its title/basisNote props in `web/src/LabTrace.jsx`, never the default "What Privilege did", and `.lab-trace .gw-lead` is hidden in `web/app.css` because the panel is byte-pinned): `POST /api/run` attaches a `trace` per call (`server/src/cedarTrace.js`, decisions `checked` because `callTool` computed them; a check an earlier refusal never reached is `skipped`). Vendored byte-for-byte, each with a pin file: `web/src/top-menu/*` (top-menu.sha256), `web/src/components/JsonPane.*` and `VerifyMark.*` (their .sha256), `web/src/gateway-trace/*` and `server/src/gatewayTrace.js` (gateway-trace.sha256), `web/standalone-ui.css` (scripts/standalone-ui.sha256), `test/kit/demo-kit-conformance.mjs` (test/kit/demo-kit-conformance.sha256), `scripts/check-no-ai-attribution.sh` (scripts/check-no-ai-attribution.sha256). Never hand-edit a pinned file; re-vendor with cp, then re-pin.
- Pure parts of the real probe (env validation, verdict classification) are in `scripts/real-probe-lib.mjs` and tested without a network.
- Honesty (rule 2): what was measured on 2026-11-16 is one real agent, two Active policies, one refusal (-32600, text on the page), and one first poll about 7 seconds after creation (one observation, not a propagation time). Everything else on the page is simulated or UNVERIFIED and says so: act as text, the no-token wording, Candidate not enforced (console documentation, not re-run), RequiredClaims, exact vs substring matching, the Cedar lines around the `contains(...)` test. Never write "verified", "validated", "never matches", "Cedar has no regex" or "a different agent was refused"; `test/page-fixes.test.jsx` and `test/honesty-text.test.js` fail on them. The real probe has never been run against a real tenant (its assumptions are listed on the page, in the README and in the talk track).
- The diagram is the diagram-studio repo's own flow (`CEDAR_ACT_SUB_FLOW`, id `cedar-act-sub-flow`), vendored byte for byte in `web/src/studio-data/` with `studio-data.sha256` (re-vendor from the studio, never edit) and looked up by name (`getDiagram("cedar-act-sub-flow")`, `web/src/diagram-data.js`); there is no lab-local diagram file. Simulate finds arrows by the boxes they join. The page never throws on an unreachable server: `postJson` answers status 0 and the page shows the error with a Retry.
- Real is script-only (builder's choice, not yet signed off by the owner, README "Modes").
- Header controls: Help, version, Shelf and Talk track come from the shared TopMenu props. The dialogs are vendored byte for byte, each with its pin file: `web/src/floating-dialog/*`, `web/src/help-dialog/*`, `web/src/talk-track/*` and `web/src/components/ShelfLink.jsx` (`ShelfLink.sha256`); `test/vendored-pins.test.js` and `scripts/repo-checks.mjs` check them. The lab supplies only content: `web/src/helpContent.js` (Help) and `docs/talk-track.md` read at build time by `web/src/talkTrack.js` (a test fails when the doc's shape changes). The version is package.json's, set at build time by `vite.config.js` (`__LAB_VERSION__`). The Shelf link shows only when `/api/shelf` answers a `shelfUrl` (SHELF_URL, or the shelf behind the lab-proxy); the lab works with no shelf.
